# Simulador Power BI

Práctica de Power Query, modelo de datos y DAX directamente en el navegador, sin instalar nada.
Incluye tres ejercicios guiados con verificación automática:

1. **Integrantes** (bd_integrantes_Esp.xlsx): limpieza, relación, columnas, medidas y KPI.
2. **Datos de servicio**: CALCULATE, KPI con tendencia y segmentadores.
3. **Alumnos y Notas** (modelo de examen, Clase 5): las 7 consignas y la rúbrica.

Abrir `index.html` o usar el enlace de GitHub Pages del repositorio.

## Archivos
- `index.html`: el simulador (un solo archivo, funciona sin conexión salvo la tipografía).
- `PowerBI_Practica_Rendimiento.xlsx`: Excel con las hojas Alumnos y Notas (datos inventados) para repetir el Ejercicio 3 en Power BI Desktop.
- `Guia_Practica_PowerBI.md`: guía de práctica con fórmulas DAX y resultados esperados.

Los datos de práctica son ficticios o de material de curso. El progreso se guarda en el navegador de quien lo usa.
